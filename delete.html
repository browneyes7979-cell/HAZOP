데이터 삭제 요청

AI 법규비서 (AI Law Secretary)
최종 수정일: 2026년 6월 29일

AI 법규비서는 이용자의 개인정보 보호를 위해 데이터 삭제 권리를 보장합니다. 본 페이지는 이용자가 앱 내에서 수집된 데이터를 삭제하는 방법을 안내합니다.

AI 법규비서는 익명으로 작동하며, 이름·이메일·전화번호 등 개인 식별 정보를 수집하지 않습니다.

1. 수집되는 데이터 종류

AI 법규비서가 수집하는 데이터는 다음과 같습니다:

  • FCM 토큰: 푸시 알림 발송용 (익명 기기 식별자)
  • 알림 설정 정보: 사용자가 설정한 알림 받을 상위법, 키워드
  • 광고 ID: Google AdMob 광고 표시용
  • 앱 사용 통계: Firebase Analytics 익명 데이터

2. 가장 빠른 데이터 삭제 방법

METHOD 01 — RECOMMENDED

앱 삭제 (가장 빠름)

박상필님 폰에서 AI 법규비서 앱을 삭제하면:

  • FCM 토큰 즉시 무효화 → 다음 푸시 발송 시 자동으로 Firestore에서 삭제됨
  • 광고 ID 더 이상 사용 안 됨
  • 로컬 즐겨찾기 데이터 삭제

대부분의 사용자는 이 방법으로 충분합니다.

METHOD 02

앱 내 알림 설정 해제

앱을 계속 사용하면서 알림만 끄려면:

  1. AI 법규비서 앱 실행
  2. 하단 메뉴 설정 탭 선택
  3. 02 - NOTIFICATIONS 섹션에서 푸시 알림 OFF

알림 OFF 시 Firestore에서 해당 사용자 데이터가 더 이상 사용되지 않습니다.

METHOD 03

완전 데이터 삭제 요청

Firestore에 저장된 데이터의 완전한 삭제를 원하시면 다음 이메일로 요청해주세요:

요청 이메일 주소:

ailawsecretary.app@gmail.com

이메일 제목: [데이터 삭제 요청] AI 법규비서

본문에 포함할 내용:

  • 요청 사유 (선택사항)
  • FCM 토큰 (앱 → 설정에서 확인 가능, 모르면 빈 칸 OK)

요청 접수 후 3 영업일 이내에 데이터가 완전히 삭제됩니다.

3. 삭제되는 데이터 목록

  • Firestore에 저장된 FCM 토큰
  • 알림 설정 정보 (상위법, 키워드)
  • 앱 사용 통계 (Firebase Analytics)
  • 광고 ID 연계 정보

4. 삭제 후 처리

데이터 삭제 후:

  • 이전에 등록된 FCM 토큰은 더 이상 푸시 알림을 받지 않습니다
  • 알림 설정은 초기화되며 복구할 수 없습니다
  • 앱을 다시 설치하면 새로운 익명 토큰으로 처음부터 시작됩니다

5. 보유 의무가 있는 데이터

다음의 경우 일부 데이터가 일정 기간 보관될 수 있습니다:

  • Google Firebase 시스템 로그: 최대 14개월 (Firebase 자체 정책)
  • Google AdMob 광고 노출 데이터: AdMob 정책에 따름
